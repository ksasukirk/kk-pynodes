## 📖 简介

KK-PyNodes 是一个现代化的可视化节点编程环境，旨在让 Python 编程更加直观、高效。通过拖拽节点和连接的方式，您可以快速构建复杂的工作流，无需手写大量代码。

### ✨ 为什么选择 KK-PyNodes？

- 🎯 **直观易用**：通过拖拽和连接节点来编程，无需记忆复杂语法
- 🔄 **实时预览**：即时执行节点图，快速查看结果
- 🎨 **丰富节点库**：涵盖数学、字符串、文件、图像处理等多个领域
- 📦 **节点组系统**：封装常用功能，提高复用性
- 🎭 **多主题支持**：深色、亮色、粉色等多种主题任您选择
- 💾 **导出功能**：将节点图导出为 Python 脚本或可执行文件

## 🌟 核心功能

### 🎨 可视化节点编辑
- **直观的拖拽界面**：通过鼠标操作创建和连接节点
- **多标签页支持**：同时编辑多个项目
- **撤销重做系统**：支持 `Ctrl+Z` / `Ctrl+Y`，放心进行实验性操作
- **缩放和平移**：自由调整画布视图，处理大型节点图

### 📦 节点组系统
- **创建节点组**：选中多个节点封装为可复用的节点组
- **编辑模式**：使用 `Tab` 键进入节点组内部编辑
- **节点组库**：管理和浏览内置及自定义节点组
- **智能输入输出**：自动识别节点组的输入输出端口

### 🖼️ 图像处理能力
- **基础操作**：读取、保存、显示、裁剪、缩放、旋转
- **色彩转换**：RGB、灰度、HSV 等色彩空间转换
- **图像增强**：亮度、对比度、饱和度调整
- **滤镜效果**：模糊、边缘检测、颜色反转等

### 📦 包管理器
- **虚拟环境**：为每个项目创建独立的 Python 环境
- **依赖管理**：可视化安装、卸载、更新 Python 包
- **项目隔离**：避免不同项目间的依赖冲突

### ↩️ 撤销重做系统
- **完整历史记录**：支持节点添加、删除、移动、属性修改等所有操作
- **多级撤销**：智能的历史记录栈管理
- **快捷操作**：`Ctrl+Z` 撤销，`Ctrl+Y` / `Ctrl+Shift+Z` 重做

### 🔧 编译与导出
- **Python 脚本**：将节点图导出为可读的 Python 代码
- **可执行文件**：使用 PyInstaller 打包为 `.exe` 文件
- **自定义图标**：为导出的程序设置自定义图标

## 🚀 快速开始

### 首次使用

1. 程序启动后会显示欢迎页面
2. 点击"新建节点图"开始创建您的第一个项目
3. 从左侧节点库中双击节点添加到画布
4. 拖拽节点端口创建连接
5. 按 `F5` 执行节点图查看结果

## 🎯 基本操作

### 节点操作

| 操作 | 方法 |
|------|------|
| 添加节点 | 从节点库拖拽到画布，或双击节点库，或右键画布选择 |
| 移动节点 | 左键拖拽节点 |
| 删除节点 | 选中节点后按 `Delete` 键 |
| 编辑属性 | 选中节点，在右侧属性面板编辑 |
| 创建连接 | 拖拽节点输出端口到另一个节点的输入端口 |
| 删除连接 | `Shift` + 右键划线删除 |

### 画布操作

| 操作 | 方法 |
|------|------|
| 平移画布 | 中键拖拽或空白处右键拖拽 |
| 缩放画布 | 鼠标滚轮 |
| 框选节点 | 左键拖拽空白区域 |
| 执行节点图 | 按 `F5` 或点击工具栏执行按钮 |
| 查看执行进度 | 执行时当前节点会以绿色边框高亮显示 |

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 新建节点图 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+S` | 保存项目 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+Z` | 撤销操作 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做操作 |
| `Ctrl+T` | 新建标签页 |
| `Ctrl+W` | 关闭标签页 |
| `Ctrl+B` | 编译为 exe |
| `F5` | 执行节点图 |
| `Delete` | 删除选中项 |
| `Tab` | 进入/退出节点组编辑 |
| `Esc` | 退出节点组编辑 |

## 🛠️ 开发和扩展

### 自定义节点开发

您可以创建自己的节点！参考 `custom_nodes/example_custom_node.py` 示例：

```python
from core.base_node import BaseNode

class MyCustomNode(BaseNode):
    """自定义节点示例"""
    
    def __init__(self):
        super().__init__()
        self.title = "我的节点"
        self.category = "自定义"
        
        # 添加输入输出端口
        self.add_input("输入")
        self.add_output("输出")
    
    def execute(self):
        input_value = self.get_input_value(0)
        # 处理逻辑
        result = f"处理结果: {input_value}"
        self.set_output_value(0, result)
```

将文件保存到 `custom_nodes/` 目录，重启程序后即可使用。
